# String file for the Rediscover Releases plugin

PLUGIN_REDISCOVER_RELEASES
	EN	Rediscover Releases

PLUGIN_REDISCOVER_RELEASES_DESC
	EN	A list of random releases that prefers albums with no recent plays: a Material skin home row, a My Music browse entry and a Don't Stop The Music mix.

PLUGIN_REDISCOVER_RELEASES_ABOUT
	EN	This plugin provides a list of random releases that follow a well-defined criteria: it prioritizes albums with no recent playbacks, supports restricting the genre list, lets you choose how often the list is regenerated, and offers deep configuration. The home row needs the Material skin. The list persists for a configurable number of hours; releases on it that get played in full are removed until the next regeneration.<br><br>After adding this plugin, enable the new <b>Rediscover Releases</b> row in Material's <i>Settings &gt; Interface</i> (home screen rows) and set the desired position. You can then save that setup as the default for all Material clients and apps.<br><br>The list is also an entry in <i>My Music</i>: in Material, enable it under <i>Settings &gt; Browse modes</i>. With a Library View selected on the player, that entry shows only the albums in it. And <i>Don't Stop The Music</i> can use it (<i>Rediscover Releases</i> in the player's Don't Stop The Music settings) to add albums from the list when the queue runs out.
